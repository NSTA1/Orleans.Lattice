# Orleans.Lattice.Api.Backup.Grpc

Optional, opt-in **gRPC transport binding** for
[Orleans.Lattice.Api.Backup](https://github.com/NSTA1/Orleans.Lattice).

This release is **scaffolding only**: it reserves the package id and the
serialization-alias prefix that the code-first, Orleans-serialized gRPC binding
and client for the backup control facade will build on. There is no runtime
behaviour yet; the gRPC service and client are layered by later releases.
