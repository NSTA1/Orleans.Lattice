# Orleans.Lattice.Membership

Identity, authorization and enforcement add-on for [`Orleans.Lattice`](https://github.com/NSTA1/Orleans.Lattice).

> **Scaffolding only.** This release is an empty, inert package. It establishes the compiling, packaged home into which later membership features land. It exposes no public API beyond the namespace and takes no dependency on the core read/write path, so it has zero runtime cost.

## Status

The package is a placeholder. Future releases will add the identity, authorization, and enforcement surface tracked on [GitHub Issues](https://github.com/NSTA1/Orleans.Lattice/issues). Until then there is nothing to register and nothing to call.

See the [Membership documentation](https://github.com/NSTA1/Orleans.Lattice/blob/main/docs/lattice.membership/README.md) for the package boundary and the tracked feature index.
