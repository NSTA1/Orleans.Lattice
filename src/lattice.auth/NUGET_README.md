# Orleans.Lattice.Auth

Authorization and enforcement add-on for [`Orleans.Lattice`](https://github.com/NSTA1/Orleans.Lattice).

> **Scaffolding only.** This release is an empty, inert package. It establishes the compiling, packaged home into which later authorization features land. It exposes no public API beyond the namespace and takes no dependency on the core read/write path, so it has zero runtime cost.

## Status

The package is a placeholder. Future releases will add the authorization and enforcement surface tracked on [GitHub Issues](https://github.com/NSTA1/Orleans.Lattice/issues). Until then there is nothing to register and nothing to call.

See the [Auth documentation](https://github.com/NSTA1/Orleans.Lattice/blob/main/docs/lattice.auth/README.md) for the package boundary and the tracked feature index.
